# Security policy

## Supported versions

The latest `0.1.x` release receives security fixes while the project remains a pilot.

## Reporting a vulnerability

Do not publish suspected vulnerabilities, credentials, private prompts, source contents, or exploit details in a public issue. Use this repository's private vulnerability reporting channel. If that channel is unavailable, open a minimal issue requesting a private contact method without including sensitive details.

Include the affected version, platform, reproduction conditions, impact, and any safe mitigation. Maintainers will acknowledge a complete report when available and coordinate disclosure after a fix or documented mitigation.

The plugin contains instructions and metadata only. Reports involving unexpected hooks, MCP servers, executables, credential access, permission changes, cross-project disclosure, model-pin substitution, or bypassed Sensitive-route acceptance checks are in scope.
